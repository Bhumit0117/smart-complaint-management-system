HOW IT WORKS

A shared path from concern to closure.

Smart Complaint System is a static frontend prototype designed for a university project.

1. Submit

Choose the relevant department, explain what happened, select priority, and optionally add images.

2. Triage

Admin teams review submissions and route them to Facilities, IT, Library, Hostel, or Academic Services.

3. Update

Students can see the current state and a clear history of actions.

Prototype note: There is no backend, real authentication, database, or AI integration. AI-assisted categorisation is a future enhancement.
